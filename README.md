# АмурТранс Контроль — учебный дашборд

Интерактивный Python Dash-дэшборд для варианта 8: процесс обработки заказов транспортной компании. Данные в `demo_orders.csv` синтетические; это не рабочая аналитика компании.

## Запуск

1. Установить Python 3.10 или новее и создать виртуальное окружение: `python -m venv .venv`.
2. Активировать окружение и выполнить `pip install -r requirements.txt`.
3. Выполнить `python app.py` и открыть `http://127.0.0.1:8050`.

Команда `python generate_sample.py` повторно создаёт демонстрационный CSV с фиксированным seed 8.

## Использование

Панель показывает четыре KPI, динамику заявок, структуру статусов, распределение фактических сроков, связь планового срока со стоимостью и реестр заказов. Период, статусы и перевозчик фильтруют все элементы одновременно. В таблице есть сортировка и дополнительный поиск по столбцам, в графиках — интерактивные подсказки. Кнопка «Загрузить CSV» заменяет демоданные пользовательским файлом без записи на сервер.

CSV в UTF-8 до 5 МБ должен содержать поля `order_id,created_at,origin,destination,status,carrier,planned_hours,actual_hours,price_rub,documents_complete`. Даты имеют формат `ГГГГ-ММ-ДД`. Статусы: «На согласовании», «Запланирован», «В пути», «Доставлен», «Закрыт». Для незавершённых заказов `actual_hours` может быть пустым. Ошибочный файл выводит сообщение и возвращает демоданные.

Код Dash запускает Python-сервер и не работает как статическая страница GitHub Pages. Для Vercel Flask-приложение экспортируется как `app` в корневом `app.py`, без дополнительного перенаправления маршрутов. Репозиторий Wiki и приложение — разные части учебного проекта.
